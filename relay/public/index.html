BEFORE YOU INSTALL

A preview, with clear limits.

This is a development build for Android TV and Google TV running Android 8 or later. Compatibility with individual models has not yet been verified. It cannot install on Samsung Tizen, LG webOS, Roku, or Apple TV.

Both APKs are signed with development keys. It is intended for evaluation, and is not a production release.

Getting started

  1. Install the TV preview using the installation method your TV supports.
  2. Open TV Home and choose favorite apps or a scene.
  3. The publisher must configure online services before phone control is available in a distributed build.
  4. Enter the pairing code in the companion app, then approve the account on the TV.

The Android phone preview is available above. The iPhone companion source is included in the project; a signed iPhone release and store downloads are not available yet.
